# Code of conduct

SPIDER welcomes careful technical disagreement and contributions from people of every background and experience level.

## Expected behaviour

- Be respectful, specific and patient.
- Critique evidence, definitions and code; do not attack people.
- Make room for questions and different levels of fluency.
- Protect private source code, personal information and credentials.
- Accept maintainer decisions about scope while remaining free to explain a different view.

## Unacceptable behaviour

Harassment, threats, discrimination, sexualised attention, deliberate humiliation, doxxing, spam and sustained disruption are not accepted in project spaces or private project-related communication.

## Reporting

Use GitHub's report-abuse controls for urgent or private conduct reports. For project moderation, open an issue that contains no private information and ask the maintainer for a private follow-up channel.

Maintainers may edit or remove contributions, comments or other participation that violates this code and may temporarily or permanently restrict participation. Responses will be proportionate to the conduct and its impact.

## Scope

This code applies in the repository, issue tracker, pull requests, discussions and other spaces where someone represents the SPIDER project.
